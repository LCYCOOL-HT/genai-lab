# 生成式 AI 作品集

一個程式零基礎的上班族，在生成式 AI 課程中每堂課用 AI 完成的作品與過程紀錄，寫給公司同事參考：看看 AI 可以怎麼用在工作上。

## 內容

| 堂 | 作品 |
|---|---|
| 1 | 用 AI 畫出一顆「可麗露」 |
| 2 | 訓練一個認得手寫數字的 AI |
| 3 | 潛力股雷達：設計一個 AI 要看什麼、猜什麼 |
| 4 | 和 AI 一起設計真正好用的 Prompt |
| 5 | 化工人的一天：3D 工安教育遊戲 |

## 怎麼看

- 線上：開啟本 repo 的 GitHub Pages
- 本機：直接用瀏覽器開 `index.html`，不需要安裝任何東西

## 怎麼新增一堂

這個專案的規則都寫在 [CLAUDE.md](CLAUDE.md)。用 Claude Code 開啟這個資料夾，說「新增第 N 堂」，AI 會依照規則讀取作業、挑截圖、建立頁面，並登記到 `assets/js/lessons.js`，首頁和導覽會自動更新。
