不同的 AI 對話模型：認識 LLM API

免費約 3 分鐘讀完

ChatGPT、Gemini 這些 App 背後，是不同公司訓練的 LLM，就像不同的「大腦」。透過 API，程式不用打開 App 就能直接請這些大腦回答，也因此可以把同一個問題交給不同的大腦，比較誰答得好。第 4 堂的作業就是這樣做的。

01App 是外殼，LLM 才是大腦

ChatGPT、Gemini 這些 App 是你看得到的「外殼」，裡面負責思考、回答的「大腦」叫做 LLM（大型語言模型），也就是 AI 聊天助手那頁介紹的「很會猜下一個字」的 AI。

不同公司訓練出來的大腦不一樣，同一個問題，答得好不好也會不一樣。那這些大腦來自哪裡？

開源模型是什麼？ 模型可以下載到自己的電腦或公司伺服器上跑，資料不用傳出去，比較安全；但需要很強的電腦，一般個人電腦通常跑不動。

想知道哪個模型比較強，可以參考 Arena、Artificial Analysis 這類評比網站。不過課堂上也提醒：最準的還是用自己熟悉的工作題目親自測，才知道哪個最適合你。

03不開 App 也能用：API 是直通大腦的窗口

平常我們是打開 App 跟大腦聊天。API 則是讓「程式」直接找大腦的窗口：不用進店裡坐下，把點單遞進窗口，就能拿到餐點。

  • 能做什麼：程式可以自動一次問很多問題，或把 AI 接進自己的系統。公司的內部 AI 平台、很多 AI 小工具，背後都是這樣做的。
  • 要付費嗎：通常是用多少付多少，也有些平台提供免費額度。
  • 專門提供 API 的平台New：例如 Groq，可以用同一個窗口呼叫開放下載的模型（第 7、8 堂用它呼叫 gpt-oss-120b）。它有免費額度，但短時間內問太多次會被暫時擋下（第 8 堂遇到的錯誤代碼 429），等一下再試就好。
  • API 金鑰：使用 API 需要一組「金鑰」，就像會員卡，絕對不能給別人或放到網路上，不然別人可以用你的額度。

04所以可以把同一題交給不同的大腦比較

因為每家的大腦都能用同樣的方式找到，就能公平地比較。第 4 堂用的方法：同一份指令，每個 AI 都開新對話，再用同一張評分表逐條打分。這樣才看得出差別，而不是憑感覺。詳細過程可以看第 4 堂的作品。

New 第 6 堂也用同一個測試情境，比較大模型 gpt-6-luna 和小模型 gpt-5.4-nano，再請第三個模型 gpt-5.6-terra 當評分員，避免「自己評自己」。結果小模型對話還不錯，但寫報告時會自己亂填，需要給它可以照抄的模板。詳細過程可以看第 6 堂的作品。
